# KeyMouseSyncReplica

C# WinForms 多窗口键鼠同步器。当前版本只保留 Windows 消息同步：捕获主操作窗口上的键鼠事件，并通过 `PostMessage` 转发到目标窗口。

## 运行

构建输出位于：

`bin\Release\net9.0-windows\win-x86\publish\KeyMouseSyncReplica.exe`

程序已配置为启动时请求管理员权限。Windows 消息同步通常需要程序权限不低于目标窗口权限，否则钩子捕获或消息投递可能受系统限制。

## 运维构建网站

`ops-web` 是本机使用的构建页面（Vite + React + TailwindCSS，附带一个本机 Node 后端执行构建）：

- 双击 `ops-web\start.cmd`，或在 `ops-web` 目录执行 `npm start`，然后打开 http://127.0.0.1:4170
- 点击构建按钮即执行 `dotnet publish -c Release`，页面实时显示日志。构建前可在页面上选择「构建方式」（选择会记在浏览器里）：
  - **打包 zip 并下载**（默认）：产物打包为 zip 放在 `ops-web\artifacts`，可直接下载
  - **直接构建到项目文件夹**：不打包 zip，直接发布到项目根目录的 `publish\`，完成后可勾选「构建完成后直接运行」，也可随时点结果卡片上的「运行」启动
- 程序要求管理员权限，所以「运行」会弹出 UAC 确认窗口。程序还在运行时无法覆盖 `publish\` 里的文件，再次用文件夹模式构建前请先手动关闭它（页面会提前提示）
- 开发页面时在 `ops-web` 目录执行 `npm run dev`（前端 5173，后端 4170）
- 该服务仅监听 127.0.0.1、无需登录；同一时间只允许一个构建运行

## 使用流程

1. 以管理员权限启动程序。
2. 按住左侧十字图标，拖到目标窗口后松开，即可把窗口加入列表；也可以把鼠标移动到目标窗口上后点击 `添加鼠标`，或按鼠标前进侧键（XButton2）添加当前光标所在窗口。
3. 选择列表中的源窗口，点击 `设置为主窗口`。
4. 勾选 `同步键盘操作` 或 `同步鼠标操作`。
5. 选择一个目标窗口后，可点击 `测试消息同步` 检查目标窗口是否接受 `PostMessage` 投递。
6. 点击 `开启同步`。程序运行期间也可以按鼠标后退侧键（XButton1）快捷开启或关闭同步，按鼠标前进侧键（XButton2）添加当前光标所在窗口。

## 说明

同步只在鼠标位于主操作窗口内时转发鼠标消息；键盘消息要求主操作窗口处于前台或焦点在其子窗口内。

`测试消息同步` 使用 `WM_NULL` 作为低副作用探针，只确认目标窗口消息队列是否接受投递。真实键鼠同步效果仍取决于目标程序是否处理对应的 `WM_KEY*`、`WM_SYSKEY*` 和 `WM_MOUSE*` 消息。
